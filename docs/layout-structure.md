# 타로 한 장 — 레이아웃 구조도

## 화면 흐름
```
home (카드 선택) → flip (3D 뒤집기) → result (가로 스와이프 4페이지)
```

## 홈 화면 (home)

```
┌─────────────────────┐
│     타로 한 장       │  ← 헤더
├─────────────────────┤
│  [연속 N일째] chip   │  ← 스트릭 배지
├─────────────────────┤
│       ◎              │  ← MysticEye 모티프 (float 애니메이션)
│  오늘의 카드를 골라보세요│

│                     │
│  ╭─╮╭─╮╭─╮╭─╮╭─╮  │  ← 부채꼴 5장 (CardFan)
│  │1││2││3││4││5│    │    -15° ~ 15° 회전
│  ╰─╯╰─╯╰─╯╰─╯╰─╯  │    transform-origin: center 160%
│                     │    탭 → 선택 카드 scale(1.15) glow
```
